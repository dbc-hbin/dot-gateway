This is a public source-only recovery edition. There is no new blanket license for all code in the repository. The existing third-party terms remain attached to the applicable components; public repository visibility does not by itself relicense the user's original project code.

Preserve the included Python license and Unicode copyright/permission notice with these generated data. Official references: https://docs.python.org/3.12/license.html and https://www.unicode.org/license.txt

## External dependencies

Go and Node implementations are installed separately using the exact lockfiles; no Go module cache, node_modules, Chromium, Go runtime distribution or compiled binary is bundled. A courtesy inventory preserves the available top-level LICENSE/NOTICE/COPYING files from all 24 declared Go module/version pairs, Playwright and playwright-core 1.63.0. `third-party-notices/INDEX.json` records these exact copied notice hashes.

Dependency license texts may describe other software not actually bundled in this source-only tree. For later executable or full dependency redistribution, inspect and preserve all applicable notices in the complete downloaded distributions, including nested notices and browser/toolchain distribution requirements. This source-only notice inventory is not a claim that arbitrary future binary packages meet every license obligation.
